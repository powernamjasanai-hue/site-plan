# 인트로 모듈

## 목적
오프닝으로 고객 문제 상황 정의 / 제안 서비스 정리 / 이후 서비스 내용 확인 유도

## 사용법
- 프롬프트에 고객과 대화 내용 넣기 → 글 작성
- 복붙

현재 저희가 제안드릴 수 있는 서비스는

(고객의 문제 상황에 대한 설명 - 장기적 관점은 N2W, 히트콘, 숏폼 제안 / 단기적 관점은 CPA 제안)

### 서비스 안내 유도

자세한 내용 확인하러 가기를 클릭하셔서
포트폴리오, 진행 프로세스, 견적 등을 확인하실 수 있습니다.

## 사용 시나리오

1. 고객과 통화/미팅 완료
2. 대화 내용을 프롬프트에 입력
3. 자동 생성된 문제 상황 문단 확인
4. 적합한 서비스 모듈 선택 (N2W, 숏폼, CPA, SEO 블로그)
5. 인트로 + 서비스 모듈 + 아웃트로 조합
6. 이메일 또는 제안서로 발송
