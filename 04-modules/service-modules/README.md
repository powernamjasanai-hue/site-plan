# 서비스 모듈

## 목적
인트로 모듈에서 제안하는 서비스를 소개하는 글 덩어리

## 사용법
제안 요청을 받은 서비스 모듈 선택하여 복붙

## 서비스 선택 가이드

### 장기적 관점
- **N2W**: 네이버 블로그 → 워드프레스 확장 노출
- **SEO 블로그 (히트콘)**: 구글 SEO 복리식 블로그 마케팅
- **숏폼 마케팅**: 3채널 브랜딩 및 이름 검색 유도

### 단기적 관점
- **CPA 마케팅**: 메타 광고 기반 즉시 상담 유입

- **서비스 안내 페이지**: [퍼소나비_N2W 서비스 안내](https://www.notion.so/_N2W-29d56a3143c780fcaa1adc4af17c131a?pvs=21)

### 02 숏폼 서비스 안내 모듈
- **헤드 카피**: 3채널 동시 노출, 숏폼으로 '내 이름'을 검색하게 만드세요
- **상세 내용**: `/01-input-data/services/shortform.md` 참조
- **서비스 안내 페이지**: [퍼소나비_숏폼 서비스 안내](https://www.notion.so/_-29d56a3143c7807fa122ed2ea6f33572?pvs=21)

### 03 CPA 마케팅 서비스 안내 모듈
- **헤드 카피**: 광고부터 랜딩, 광고 운영까지 수임만 받으시면 됩니다
- **상세 내용**: `/01-input-data/services/cpa.md` 참조
- **서비스 안내 페이지**: [퍼소나비_CPA 서비스 안내](https://www.notion.so/_CPA-29d56a3143c781359656f957d7f18033?pvs=21)

### 04 SEO 블로그 마케팅 서비스 안내 모듈 (히트콘)
- **헤드 카피**: 지속적으로 쌓이는 복리식 블로그 마케팅, SEO는 가능합니다

## 모듈 조합 예시

### 장기 마케팅 구축 고객
**인트로** → **N2W + 숏폼** → **아웃트로**

### 단기 성과 필요 고객
**인트로** → **CPA** → **아웃트로**

### 풀 패키지 고객
**인트로** → **N2W + 숏폼 + SEO 블로그 + CPA** → **아웃트로**

### 콘텐츠 중심 고객
**인트로** → **N2W + SEO 블로그** → **아웃트로**
