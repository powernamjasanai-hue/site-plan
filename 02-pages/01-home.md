## 💡 전체 메시지 프레임워크

**핵심 통합 베네핏:**
- **검색되고 (SEO/N2W)** - 구글·다음·빙에서 찾아옴
- **발견되고 (숏폼)** - 릴스·숏츠·틱톡에서 먼저 만남
- **기억되는 (복리식 자산)** - 시간이 지날수록 쌓이는 디지털 자산

**서비스의 공통 가치:**
- 광고비 0원 또는 최소화, 복리식 구조
- 다채널 노출 (검색엔진 + 영상 플랫폼)
- 브랜드 각인 및 온라인 존재감 구축
- 장기적 ROI, 쌓이는 마케팅 자산

## 섹션 3: As Is - To Be 섹션

### 📐 레이아웃
- **구조**: 2열 대비형 (좌: As-Is / 우: To-Be)
- **배경**: 좌측 어두운 색상 / 우측 밝은 색상 (대비 효과)
- **중앙**: 큰 화살표 (→) 또는 "VS" 텍스트

### ✍️ 카피라이팅

**섹션 헤드카피** (50자 이내)
```
퍼소나비와 함께하면 달라집니다
```

---

### 📌 좌측: Before (지금은...)

**소제목**
```
❌ Before
```

**불릿 포인트** (4개)
```
• 네이버만 의존, 구글·유튜브 고객 놓침
• 월 300만원 광고비, 끄면 유입 0
• 블로그 운영할 시간 없고, 외주는 불신
• 경쟁사는 검색 1페이지 + 숏폼 100만 조회
```

---

### 📌 우측: After (퍼소나비와 함께하면...)

**소제목**
```
✅ After
```

**불릿 포인트** (4개)
```
• 검색창(구글·다음·빙) + SNS(릴스·숏츠·틱톡) 모두 노출
• 광고비 0원, 복리식으로 쌓이는 마케팅 자산
• 콘텐츠 제작부터 발행까지 전담, 시간 절약
• 매월 10건+ 신규 문의 + 이름 검색 급증
```
