## ICP 정의 목적

이 문서는 퍼소나비의 **Ideal Customer Profile (ICP)**을 명확히 정의하여 다음 목적을 달성하기 위해 작성되었습니다:

1. **마케팅 메시지 정교화**: 타겟별 맞춤 메시지 설계
2. **콘텐츠 전략 수립**: ICP별 블로그 콘텐츠 기획
3. **리드 스코어링**: 온도별 리드 분류 및 우선순위 설정
4. **서비스 개선**: 고객 페인포인트 및 니즈 기반 서비스 개선
5. **영업 전략**: 세일즈 콜 시 활용할 고객 프로필 참고 자료

## 공통 페인포인트 (5가지)

### 1. 네이버 중심 마케팅의 한계

**문제점**:
- 검색 고객의 40%를 놓침 (구글, 다음, 빙 고객)
- 네트워크 펌에 밀려 개인 개업자 불리
- 저품질 필터에 걸려 애써 쌓은 콘텐츠 매장
- 플랫폼 의존도 높음 (돈 드려 고객을 뺏김)

**고객 목소리**:
```
"검색 고객 40%, 네이버 '밖'에 있습니다"
"네이버 블로그는 네트워크 펌의 블로그에 밀리는 경향"
"저품질 필터와 알고리즘 변화로 애써 쌓은 콘텐츠가 점점 묻힘"
```

**인풋 데이터 근거**:
- `sales-call-insights.md` 33-43줄: "네이버 중심 마케팅의 한계"

---

### 2. AI 검색 시대 대응 필요

**문제점**:
- 네이버 블로그는 AI의 답변 출처로 잡히지 않음 (폐쇄형 플랫폼)
- GPT, Perplexity 등 AI 검색 사례 증가
- AEO (Answer Engine Optimization) 시대 준비 필요

**고객 목소리**:
```
"AI의 답변은 네이버 블로그가 아닌 구글 기반 사이트를 참조"
"요즘 AI 검색 사례가 증가하고 있으며, GPT를 통해 궁금한 점을 물어보는 경우가 많아짐"
```

**인풋 데이터 근거**:
- `sales-call-insights.md` 44-52줄: "AI 검색 시대 대응 필요"

### 3. 광고비 부담

**문제점**:

- 고객도 아닌 사람이 클릭하여 무분별한 광고비 지출

**고객 목소리**:
```

"매번 비용만 드는 네이버 블로그 마케팅에 지침"
```

**인풋 데이터 근거**:

**인풋 데이터 근거**:

## 공통 니즈 (5가지)

### 1. 다채널 노출

**니즈**:
- 네이버 → 구글, 다음, 빙, 줌 확장 노출
- 검색 고객 40% 회복

**고객 목소리**:
```
"네이버 외에 다른 매체들 구글이나 이런 데 조금 더 노출되었으면"
```

**퍼소나비 솔루션**:
- N2W (Naver to WordPress): 네이버 블로그 → 구글·다음·빙 자동 확장
- SEO 콘텐츠 제작: 구글 SEO 최적화 블로그

**인풋 데이터 근거**:
- `sales-call-insights.md` 75-77줄: "다채널 노출"

---

### 2. 복리식 마케팅

**니즈**:
- 광고 끊어도 계속 쌓이는 구조
- "쌓이는 수임 자동화 마케팅 시스템"
- "복리처럼 쌓이는 구조"

**고객 목소리**:
```
"광고 끊어도 계속 쌓이는 구조가 필요해요"
"복리처럼 쌓이는 구조를 만들고 싶어요"
```

**퍼소나비 솔루션**:
- SEO 블로그: 한 번 쌓인 글이 사라지지 않고 트래픽 복리 증가
- N2W: 네이버 블로그 글을 마케팅 자산으로 전환

**인풋 데이터 근거**:

## 온도별 리드 분류

### 🔥 뜨거움 (Hot Leads)

**특징**: 즉시 계약 가능, 예산 확보, 의사결정 권한 보유

| 이름 | 직종 | 특징 |
|------|------|------|
| 권태용 | 로펌 사무장 | 연매출 90억 규모 로펌, 11.15까지 제안서 요청 |
| 정다운 | 변호사 | 법무법인 대겸, 숏폼 관심, 심희정 변호사 소개 |
| 김용일 | 변호사 | 법무법인 현, **계약 체결** |
| 이승주 | 변호사 | 김민성 변호사 남편분 |
| 강범구 | 한의사 | 2026년 6월 강동구 개원 예정 |
| 김현수 | 세무사 | 서울, 인스타에서 유입 |
| 박정연 | 노무사 | 노무법인 마로, 부당해고 키워드 집중 |
| 이상민 | 행정사 | 대표 블로그 1개 + 지사별 8개 운영 |

**영업 전략**:
- 즉시 제안서 발송
- 줌 미팅 예약 우선 처리
- 성공 사례 및 레퍼런스 강조

---

### 🌡️ 미지근 (Warm Leads)

**특징**: 관심 있지만 즉시 계약은 어려움, 너처링 필요

| 이름 | 직종 | 특징 |
|------|------|------|
| 이동주 | 로펌 사무장 | 사무장님 |
| 최보람 | 로펌 마케터 | 법무법인 호암 마케터 |
| 박상은 | 로펌 마케팅 | 로펌 마케팅 담당 |
| 성동영 | 변호사 | 형사 전문, 네이버 블로그 200개 |
| 이소현 | 변호사 | 법무법인, 마케팅 불신 (기존 대행사 문의 0건) |

**영업 전략**:
- 이메일 뉴스레터 발송
- 블로그 콘텐츠 공유
- 리드마그넷 제공 (SEO 체크리스트, 숏폼 레퍼런스)
- 정기적인 팔로우업

## ICP별 마케팅 메시지

### 🎯 1차 타겟: 로펌 사무장

**헤드라인**:
> "마케팅 예산, 효과적으로 집행하고 계신가요?"

**본문**:
```
광고는 돈만 나가고, 블로그는 네이버에만 묻혀 있고,
숏폼은 아예 시작도 못하고, 변호사님들은 성과를 요구하시죠.

퍼소나비는 검색(SEO/N2W) + 영상(숏폼) 통합 마케팅으로
장기 ROI를 극대화합니다. 한 번 쌓인 콘텐츠가 계속 고객을 데려오는 구조를 만들어드립니다.
```

**CTA**:
```
[로펌 마케팅 가이드 받기]
```

---

### 🎯 2차 타겟: 변호사

**헤드라인**:
> "블로그 200개 작성했는데 네이버에만 묻혀 있나요?"

**본문**:
```
네트워크 펌에 밀리고, 저품질 필터에 걸리고,
유튜브·인스타에는 아예 존재하지 않아 답답하시죠.

퍼소나비는 검색창(구글·다음·빙) + SNS(릴스·숏츠·틱톡) 모두에서
당신의 이름을 각인시킵니다. 검색하고, 발견하고, 기억되는 변호사를 만들어드립니다.
```

**CTA**:
```
[변호사 마케팅 가이드 받기]
```

---

```
로펌, 세무사, 행정사, 한의사 등 100건+ 전문직 성공 사례 보유.
전문직 톤을 유지하며, 검색되고, 발견되고, 기억되는 브랜딩을 만듭니다.
```

**CTA**:
```
[전문직 마케팅 가이드 받기]
```
