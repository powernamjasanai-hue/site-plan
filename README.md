# 퍼소나비 웹사이트 리뉴얼 기획 프로젝트

**현재 버전**: v1.0

## 프로젝트 개요

전문직 마케팅 전문 에이전시 퍼소나비(PERSONAB)의 웹사이트 리뉴얼을 위한 카피라이팅 및 페이지 구조 기획 프로젝트입니다.

> 📌 **버전 관리**: 이 프로젝트는 버전 관리 시스템을 사용합니다. 자세한 내용은 [VERSION.md](VERSION.md)와 [CHANGELOG.md](CHANGELOG.md)를 참조하세요.

## 목적

- **기존**: 전문직 마케팅을 원하는 고객 DB 수집
- **변경**: 리드마그넷 터치포인트 증가 + 인바운드 컨텐츠 리드 너처링

## ICP (Ideal Customer Profile)

- **1차 타겟**: 변호사 10명 미만의 로펌 사무장
- **2차 타겟**: SEO의 가치를 이해하고, 마케팅 시스템을 구축하고자 하는 변호사

## 주요 서비스

1. **N2W**: 네이버 블로그 → 워드프레스 자동 발행 및 SEO/AEO 최적화 리라이팅
2. **숏폼 마케팅**: 릴스+숏츠+틱톡 3채널 동시 노출 브랜딩
3. **CPA 마케팅**: 메타 광고 기반 랜딩페이지 제작 및 광고 운영
4. **SEO 블로그**: 구글 SEO 최적화 블로그 콘텐츠 제작 및 운영

## 작업 순서

1. 홈 페이지 (리드마그넷 터치포인트 강화)
2. 로펌 전문 SEO 홈페이지 제작 (신규 핵심 서비스)
3. N2W (기존 페이지 리뉴얼)
4. 숏폼 마케팅 (기존 페이지 리뉴얼)
5. 블로그 (구조 기획)

## 섹션 기본 구조

- 이미지
- 헤드카피 (50자 이내)
- 본문 또는 서브카피
- 필요시 2열/3열 그룹핑 (소제목 + 본문)

## 작업 프로세스

1. 페이지별 섹션 구조 제시
2. 사용자 검토 및 피드백
3. 섹션별 카피라이팅 작성
4. 수정 및 보완
5. 다음 페이지로 진행
