# 현재 사이트 콘텐츠 분석

## 현재 사이트 구조

1. **홈페이지**: https://personab.co.kr/
2. **숏폼 마케팅**: https://personab.co.kr/숏폼-마케팅/
3. **N2W**: https://personab.co.kr/n2w/

---

## 현재 사이트의 주요 메시지

### 홈페이지
- **핵심 메시지**: AEO 시대, 콘텐츠 루프 마케팅
- **타겟**: 전문직 (명확하지 않음)
- **주요 가치**: 광고비 0원, 24시간 마케팅 직원
- **서비스 구분**: 텍스트 기반 vs 영상 기반
- **CTA**: 무료 상담 신청 (매월 10명 한정)

### 숏폼 마케팅
- **핵심 메시지**: 내 이름을 검색하게 만드는 숏폼
- **타겟**: 블로그 경쟁에 지친 전문직
- **주요 가치**: 발견 → 브랜딩 → 이름 검색
- **차별점**: 조회수가 아닌 전문성과 이름 각인
- **CTA**: 무료 상담 신청, 3개월 후 성과

### N2W
- **핵심 메시지**: 네이버 블로그 확장 노출
- **타겟**: 네이버 블로그 마케팅 비용에 지친 전문직
- **주요 가치**: 광고비 0원, 복리식 트래픽, AI 답변 최적화
- **차별점**: 수임 자동화 설계
- **CTA**: 매월 10명 한정, 1분 신청

---

## 현재 사이트의 강점

### 1. 명확한 문제 인식
- AEO 시대 변화 언급
- 네이버 중심 마케팅의 한계 지적
- AI 검색 대응 필요성 강조

### 2. 구체적인 성과 사례
- N2W: 김**, 심**, 남** 변호사 사례
- 숏폼: 조회수, 문의 증가 사례 (이미지)

### 3. 복리식 마케팅 개념
- 광고비 0원
- 쌓이는 구조
- 지속 가능한 시스템

### 4. 차별화된 접근
- 단순 마케팅 대행이 아닌 "수임 자동화 설계"
- 조회수가 아닌 "전문성과 이름 각인"

## 현재 사이트의 개선 필요 사항

### 1. ICP 불명확
- "전문직"이라는 넓은 타겟
- 로펌 사무장, 변호사 등 구체적 ICP 부재
- 업종별 맞춤 메시지 부족

### 2. 서비스 구조 혼재
- 홈에서 텍스트 vs 영상 기반 구분만
- N2W, SEO 블로그, 숏폼, CPA 등 명확한 구분 부족
- 서비스 간 관계와 시너지 설명 부족

### 3. 리드마그넷 부재
- CTA가 "무료 상담 신청"만
- SEO/AEO 체크리스트, 숏폼 레퍼런스 등 중간 단계 리드마그넷 없음
- 즉시 상담 신청 허들이 높음

### 4. 로펌 전문 서비스 페이지 부재
- 로펌 특화 SEO 홈페이지 제작 서비스 페이지 없음
- 신규 핵심 서비스인데 전용 페이지 부재

### 5. 블로그/콘텐츠 허브 부재
- 인바운드 리드 너처링 구조 없음
- ICP별 맞춤 콘텐츠 부재

### 6. Q&A 답변 미완성
- 숏폼: Q2, Q3 답변 없음
- N2W: Q2, Q3, Q4 답변 없음

## 리뉴얼 시 유지할 요소

### 1. 핵심 메시지
- AEO 시대 대응
- 복리식 마케팅
- 광고비 0원, 지속 가능한 시스템

### 2. 성과 사례
- 변호사님들 실제 성과
- 구체적인 수치와 후기

### 3. 차별화 포인트
- 수임 자동화 설계
- 이름 검색되는 브랜딩
- 콘텐츠 루프 마케팅

### 4. CTA 구조
- 매월 10명 한정 (희소성)
- 구체적인 기대 성과 (3개월 후)

## 리뉴얼 시 개선할 요소

### 1. ICP 명확화
- 1차: 로펌 사무장
- 2차: 변호사
- 업종별 맞춤 메시지

### 2. 서비스 체계화
- 홈: 전체 서비스 소개 + 리드마그넷
- 로펌 전문 SEO 홈페이지 제작 (신규)
- N2W (리뉴얼)
- 숏폼 마케팅 (리뉴얼)
- CPA, SEO 블로그 (서비스 모듈)
- 블로그 (신규)

### 3. 리드마그넷 추가
- SEO/AEO 체크리스트
- 숏폼 레퍼런스 모음
- 무료 사이트 진단
- 각 페이지에 전략적 배치

### 4. Q&A 완성
- 모든 Q&A 답변 작성
- FAQ 섹션 강화

### 5. ICP별 콘텐츠 전략
- 사무장 대상 블로그
- 변호사 대상 블로그
- 리드 너처링 흐름 설계

## 현재 vs 리뉴얼 비교

| 항목 | 현재 | 리뉴얼 (v1.0) |
|------|------|---------------|
| **타겟** | 전문직 (넓음) | 로펌 사무장 + 변호사 (구체적) |
| **목적** | DB 수집 | 리드마그넷 터치포인트 + 리드 너처링 |
| **페이지 수** | 3개 | 5개+ (로펌 SEO 홈페이지, 블로그 추가) |
| **리드마그넷** | 없음 | 3가지 (체크리스트, 레퍼런스, 진단) |
| **서비스 구분** | 텍스트 vs 영상 | N2W, 숏폼, SEO 홈페이지, CPA, SEO 블로그 |
| **CTA** | 상담 신청만 | 리드마그넷 + 상담 신청 (단계별) |
| **콘텐츠** | 서비스 페이지만 | 블로그 + 리드 너처링 |
