## 고객의 주요 페인포인트

### 1. 네이버 중심 마케팅의 한계
- **40% 고객 놓침**: 네이버만 바라보는 마케팅은 전체 시장의 절반만 보는 것
- **네트워크 펌에 밀림**: 개인 개업자가 네트워크 펌을 이기기 어려움
- **저품질 필터**: 애써 쌓은 콘텐츠가 점점 묻힘
- **플랫폼 의존도**: 돈 드려 고객을 뺏기게 됨

**고객 목소리**:
- "검색 고객 40%, 네이버 '밖'에 있습니다" (N2W 페이지 현재 카피)
- "네이버 블로그는 네이버에만 노출되어 네트워크 펌의 블로그에 밀리는 경향"
- "저품질 필터와 알고리즘 변화로 애써 쌓은 콘텐츠가 점점 묻힘"

### 2. AI 검색 시대 대응 필요
- **AI의 답변 출처로 잡히지 않음**: 네이버 블로그는 폐쇄형 플랫폼
- **GPT, Perplexity 등에서 검색 증가**: AI 검색 사례 증가
- **AEO 시대 준비 필요**: Answer Engine Optimization

**고객 목소리**:
- "AI의 답변은 네이버 블로그가 아닌 구글 기반 사이트를 참조" (N2W 페이지)
- "요즘 AI 검색 사례가 증가하고 있으며, GPT를 통해 궁금한 점을 물어보는 경우가 많아짐"

### 3. 광고비 부담
- **클릭당 5~10만원**: 광고비는 계속 오르는데 고객은 늘지 않음
- **광고 끄면 유입 0**: 매달 광고비를 써도 잠깐뿐
- **고객도 아닌 사람이 클릭**: 무분별한 광고비 지출

**고객 목소리**:
- "월 300만원 마케팅 비용, 네이버 블로그만으로는 40% 고객 놓침"
- "매번 비용만 드는 네이버 블로그 마케팅에 지침"

### 4. 마케팅 불신
- **문의 한 건도 없음**: 기존 대행사에서 문의가 아예 없었음 (이소현 변호사)
- **비용 대비 효과 의문**: 마케팅 대행사들은 그냥 일을 진행할 뿐 매출에 도움 안 됨
- **단기 성과 집착**: 초기 법무법인 특성상 단기 문의 건수에 약간 집착

### 5. 시간 부족
- **바쁜 전문직**: 블로그 직접 운영할 시간 없음
- **마케팅 전담 인력 부재**: 대표가 직접 블로그 운영 (이상민 행정사)

## 고객의 주요 니즈

### 1. 다채널 노출
- 네이버 → 구글, 다음, 빙, 줌 확장 노출
- "네이버 외에 다른 매체들 구글이나 이런 데 조금 더 노출되었으면"

### 2. 복리식 마케팅
- 광고 끊어도 계속 쌓이는 구조
- "쌓이는 수임 자동화 마케팅 시스템"
- "복리처럼 쌓이는 구조"

### 3. 즉각적 문의 유도
- 문의하기, CTA, 문의 자동화
- "검색이 되어서 사이트에 들어와서 즉각적인 효과"
- "고객 DB가 바로 오는 형태"

### 4. 전문성 유지하면서 브랜딩
- 자극적인 콘텐츠 아닌 전문직 신뢰감
- "전문직 톤을 유지하며, 업무에 지장 없이 진행"

### 5. 합리적 비용
- 월 100만원 (N2W 30건, SEO 블로그 15건)
- 3개월 계약 시 홈페이지 무료 제작
