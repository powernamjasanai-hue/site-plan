## URL 구조

### 기존 페이지 (유지)

| 페이지명 | URL | 상태 | 비고 |
|---------|-----|------|------|
| 홈 | `/` | 리뉴얼 | 리드마그넷 강화 |
| N2W | `/n2w` | 리뉴얼 | 기존 URL 유지 |
| 숏폼 마케팅 | `/shortform-marketing` | 리뉴얼 | 기존 URL 정리 필요* |

*현재 URL: `/숏폼-마케팅/` → 영문 URL로 변경 권장

### 신규 페이지

| 페이지명 | URL | 우선순위 | 비고 |
|---------|-----|---------|------|
| SEO 콘텐츠 제작 | `/seo-content-marketing` | 1 | 핵심 신규 서비스 |
| CPA 마케팅 | `/cpa-marketing` | 2 | 옵션 서비스 |
| 블로그 | `/blog` | 3 | 인바운드 리드 너처링 |
| 리소스 허브 | `/resources` | 3 | 리드마그넷 모음 |
| 회사 소개 | `/about` | 4 | 옵션 |
| 문의하기 | `/contact` | 1 | CTA 페이지 |

### URL 네이밍 규칙

- 영문 소문자 사용
- 단어 구분은 하이픈(-) 사용
- 서비스명은 명확하고 SEO 친화적으로
- 한글 URL 지양 (SEO 및 공유 최적화)

## 페이지별 상세 정보

### 1. 🏠 홈 (`/`)

**페이지 목적**
- 퍼소나비의 핵심 가치 전달
- 4가지 서비스 소개
- 리드마그넷을 통한 초기 접점 확보
- ICP(로펌 사무장, 변호사)별 맞춤 메시지

**타겟 오디언스**
- 1차: 로펌 사무장 (마케팅 담당자)
- 2차: 변호사 (SEO 관심층)
- 3차: 기타 전문직 (세무사, 행정사 등)

**핵심 메시지**
- "네이버 중심 마케팅의 한계, 검색 고객 40% 놓치고 계십니다"
- "광고비 0원, 복리식 마케팅으로 대비하세요"
- "AEO 시대, 콘텐츠 루프 마케팅이 답입니다"

**주요 CTA**
1. 무료 상담 신청 (줌 미팅)
2. SEO/AEO 체크리스트 다운로드
3. 숏폼 레퍼런스 다운로드
4. 무료 사이트 진단 신청

**상태**: 우선순위 1 (즉시 제작)

---

### 2. 📝 SEO 콘텐츠 제작 (`/seo-content-marketing`) ⭐️ 신규

**페이지 목적**
- 신규 핵심 서비스 소개
- 구글 SEO 블로그 마케팅의 가치 전달
- 복리식 장기 마케팅 개념 강조
- 히트콘 서비스 차별화 포인트 설명

**타겟 오디언스**
- 1차: 로펌 사무장 (SEO 이해도 보유)
- 2차: 변호사 (장기 자산 구축 희망)
- 특징: "복리식", "광고비 절감"에 관심 있는 고객

**핵심 메시지**
- "지속적으로 쌓이는 복리식 블로그 마케팅"
- "광고를 끄면 바로 유입 0이 되는 네이버의 한계 극복"
- "구글 SEO: 한 번 쌓인 글이 사라지지 않음, 시간이 지날수록 트래픽 복리 증가"

**서비스 구조**
1. SEO 성공 공식: 키워드 설계 + 도메인 구축 + 콘텐츠 집필
2. 6단계 프로세스
3. 기대 성과 (3개월 후)
4. 가격: 15건 기준 월 100만원

**주요 CTA**
1. 무료 상담 신청
2. SEO/AEO 체크리스트 다운로드
3. 사이트 무료 진단 신청

**상태**: 우선순위 1 (즉시 제작)

---

### 3. 📝 N2W (`/n2w`)

**페이지 목적**
- 네이버 블로그 확장 노출 서비스 소개
- 다채널 노출 (구글, 다음, 빙)의 가치 전달
- SEO/AEO 리라이팅의 차별점 강조

**타겟 오디언스**
- 1차: 네이버 블로그 운영 중인 로펌 사무장
- 2차: 네이버 블로그 200개 이상 보유한 변호사
- 특징: "다채널 확장", "검색 40% 놓침" 메시지 반응층

**핵심 메시지**
- "검색 고객 40%, 네이버 '밖'에 있습니다"
- "네이버 블로그 글 링크만 주시면 구글, 다음, 빙 확장 노출 & 마케팅 자산화"
- "한 번 작성한 글이 여러 채널에서 지속 유입 창출"

**서비스 구조**
1. 3단계 노출 구조
2. SEO/AEO 리라이팅
3. 장기 성과 (복리식)
4. 가격: Notion 링크 참조

**주요 CTA**
1. 무료 상담 신청
2. SEO/AEO 체크리스트 다운로드

**상태**: 우선순위 2 (리뉴얼)

### 4. 📝 숏폼 마케팅 (`/shortform-marketing`)

**페이지 목적**
- 3채널 동시 노출 숏폼 서비스 소개
- 브랜딩 및 이름 각인 효과 강조
- "블로그는 찾는 고객, 숏폼은 발견하는 고객" 차별화

**타겟 오디언스**
- 1차: 얼굴 노출 가능한 변호사
- 2차: 브랜딩 중시하는 로펌 사무장
- 특징: "이름 각인", "3채널 노출"에 관심 있는 고객

**핵심 메시지**
- "3채널 동시 노출, 숏폼으로 '내 이름'을 검색하게 만드세요"
- "블로그는 '이미 찾는 의뢰인' 유입, 숏폼은 '아직 모르는 의뢰인' 발견"
- "이름이 브랜드가 되는 효과"

**서비스 구조**
1. 숏폼 성공 공식: 전문성 + 대중성 + 개인 스토리
2. 6단계 프로세스
3. 기대 성과 (3개월 후)
4. 성공 사례 (변호사 팔로워 5,500+, 조회수 100만+)
5. 가격: Notion 링크 참조

**주요 CTA**
1. 무료 상담 신청
2. 숏폼 레퍼런스 다운로드

**상태**: 우선순위 2 (리뉴얼)

### 5. 📝 CPA 마케팅 (`/cpa-marketing`) ⭐️ 신규

**페이지 목적**
- 메타 광고 기반 CPA 마케팅 서비스 소개
- 즉각적 문의 유도 (단기 성과)
- 심리 분석 기반 광고 소재 차별화

**타겟 오디언스**
- 1차: 즉시 상담 유입 필요한 로펌
- 2차: 단기 성과 중시하는 변호사
- 특징: "클릭은 나오는데 상담 안 옴" 페인포인트 보유

**핵심 메시지**
- "광고부터 랜딩, 광고 운영까지 수임만 받으시면 됩니다"
- "클릭은 나오는데 상담이 안 오는 문제 해결"
- "심리 분석 기반 소재 + 전환 최적화 랜딩 + 자동화 운영"

**서비스 구조**
1. CPA 성공 공식: 심리 분석 + 카피 기획 + 최적화 운영
2. 6단계 프로세스
3. 가격: 풀패키지 250만원

**주요 CTA**
1. 무료 상담 신청

**상태**: 우선순위 2 (신규 제작)

### 여정 1: 로펌 사무장 (SEO 관심층)

```
1. 구글 검색 "로펌 SEO 마케팅"
   ↓
2. 블로그 글 도착 ("로펌 마케팅 예산 효율적으로 쓰는 법")
   ↓
3. 글 내 CTA 클릭 → SEO/AEO 체크리스트 다운로드
   (이메일 수집)
   ↓
4. 체크리스트 내 링크 → SEO 콘텐츠 제작 페이지
   ↓
5. 서비스 페이지 하단 CTA → 무료 상담 신청
   ↓
6. 줌 미팅 예약 → 계약
```

### 여정 2: 변호사 (숏폼 관심층)

```
1. 퍼소나비 인스타그램/유튜브 광고 발견
   ↓
2. 홈페이지 직접 방문
   ↓
3. 홈 히어로 섹션 → 숏폼 레퍼런스 다운로드 CTA 클릭
   (이메일 수집)
   ↓
4. 레퍼런스 내 링크 → 숏폼 마케팅 페이지
   ↓
5. 성공 사례 확인 (변호사 팔로워 5,500+)
   ↓
6. 서비스 페이지 하단 CTA → 무료 상담 신청
   ↓
7. 줌 미팅 예약 → 계약
```

### 여정 3: 로펌 사무장 (즉시 문의 필요)

```
1. 네이버 검색 "로펌 마케팅 대행사"
   ↓
2. 홈페이지 직접 방문
   ↓
3. 홈 문제 정의 섹션 읽음 ("검색 고객 40% 놓침")
   ↓
4. 솔루션 소개 섹션 → 4가지 서비스 확인
   ↓
5. 홈 CTA 섹션 → 무료 사이트 진단 신청 클릭
   ↓
6. 줌 미팅 예약 → 사이트 진단 받음 → 제안서 받음 → 계약
```

### 여정 4: 기존 고객 (재방문, 블로그 학습)

```
1. 이메일 뉴스레터 수신 (블로그 새 글 알림)
   ↓
2. 블로그 글 클릭 ("AEO 시대, 변호사 블로그 작성법")
   ↓
3. 글 읽고 관련 서비스 링크 클릭 (N2W 또는 SEO 콘텐츠 제작)
   ↓
4. 서비스 페이지 확인 후 북마크 또는 상담 신청
   ↓
5. 추후 재방문 → 계약
```

## 리드마그넷 배치 전략

### 3가지 리드마그넷

| 리드마그넷 | 타겟 고객 | 형식 | 배치 위치 | 목적 |
|----------|---------|------|----------|------|
| **SEO/AEO 체크리스트** | N2W, SEO 블로그 관심 고객 | PDF 다운로드 | 홈, SEO 콘텐츠 제작, N2W 페이지 | 이메일 수집, 서비스 인지도 향상 |
| **숏폼 레퍼런스 모음** | 숏폼 마케팅 관심 고객 | PDF 또는 노션 | 홈, 숏폼 마케팅 페이지 | 이메일 수집, 사무실 숏폼 아이디어 제공 |
| **무료 사이트 진단** | 모든 잠재 고객 | 줌 미팅 예약 | 홈, 모든 서비스 페이지 | 즉시 상담 연결, 고품질 리드 확보 |

### 페이지별 리드마그넷 배치

**홈 (`/`)**
- 히어로 섹션: 3가지 리드마그넷 버튼 (병렬 배치)
- CTA 섹션: 무료 사이트 진단 강조

**SEO 콘텐츠 제작 (`/seo-content-marketing`)**
- 페이지 하단: SEO/AEO 체크리스트 다운로드
- 사이드바 (옵션): 무료 사이트 진단

**N2W (`/n2w`)**
- 페이지 하단: SEO/AEO 체크리스트 다운로드
- 사이드바 (옵션): 무료 사이트 진단

**숏폼 마케팅 (`/shortform-marketing`)**
- 페이지 하단: 숏폼 레퍼런스 다운로드
- 사이드바 (옵션): 무료 사이트 진단

**CPA 마케팅 (`/cpa-marketing`)**
- 페이지 하단: 무료 상담 신청

**블로그 (`/blog`)**
- 글 내 CTA: 관련 서비스별 리드마그넷
- 사이드바: 3가지 리드마그넷 모음
- 글 하단: 무료 상담 신청

**리소스 허브 (`/resources`)**
- 메인 콘텐츠: 3가지 리드마그넷 상세 소개 및 다운로드

### 리드마그넷 전환 퍼널

```
1. 방문자 도착 (홈 또는 서비스 페이지)
   ↓
2. 리드마그넷 CTA 노출
   ↓
3. 이메일 입력 → 리드마그넷 다운로드
   (리드 확보)
   ↓
4. 리드마그넷 내 서비스 소개 및 링크
   ↓
5. 서비스 페이지 재방문
   ↓
6. 무료 상담 신청 → 계약
```

## 핵심 원칙

### 1. ICP 중심 메시지
- 모든 페이지는 로펌 사무장 또는 변호사를 명확히 타겟
- 페인포인트 기반 메시지 (네이버 한계, 광고비 부담)
- 솔루션 제시 (복리식, 다채널, 이름 각인)

### 2. 리드마그넷 우선
- 모든 페이지에 최소 1개 이상의 리드마그넷 배치
- 무료 상담 신청만이 아닌 중간 단계 CTA 강화
- 이메일 수집 → 너처링 → 계약 퍼널 구축

### 3. 성공 사례 강조
- 모든 서비스 페이지에 변호사 레퍼런스 배치
- 구체적 수치 강조 (팔로워 5,500+, 조회수 100만+)
- 신뢰도 향상

### 4. SEO 최적화
- 영문 URL 사용
- 페이지별 메타태그 최적화
- 블로그 장기 SEO 전략
- 구조화된 데이터 마크업

### 5. 사용자 여정 고려
- 방문 → 리드마그넷 → 서비스 확인 → 상담 신청 퍼널
- 페이지 간 자연스러운 연결
- CTA 배치 최적화
