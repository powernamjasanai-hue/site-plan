# 사이트 구조

## 기존 사이트 구조

1. 홈
2. N2W
3. 숏폼 마케팅

## 수정된 사이트 구조

### 1. 홈 (메인 페이지)
- 리드마그넷 터치포인트 강화
- 전면 리드마그넷 CTA 버튼 추가
- 4가지 서비스 소개
- ICP별 맞춤 메시지

### 2. SEO 콘텐츠 제작 (히트콘) ⭐️ **신규**
- 구글 SEO 최적화 블로그 콘텐츠 제작
- 복리식 장기 마케팅
- 핵심 신규 서비스 페이지

### 3. N2W (SEO/AEO 콘텐츠 대행)
- 네이버 블로그 → 워드프레스 자동 발행
- SEO/AEO 최적화 리라이팅
- 기존 페이지 리뉴얼

### 4. 숏폼 마케팅
- 릴스+숏츠+틱톡 3채널 동시 노출
- 브랜딩 중심 숏폼 마케팅
- 기존 페이지 리뉴얼

### 5. CPA 마케팅 (옵션)
- 메타 광고 기반
- 랜딩페이지 제작 + 광고 운영
- 서비스 모듈로 활용

### 6. 블로그 ⭐️ **신규**
- ICP별 맞춤 콘텐츠 발행
- 사무장 대상 콘텐츠
- 변호사 대상 콘텐츠
- 인바운드 리드 너처링

### 7. 리소스/리드마그넷 허브 (옵션)
- SEO, AEO 체크리스트
- 숏폼 레퍼런스 모음
- 무료 사이트 진단

---

## 리드마그넷 전략

### 리드마그넷 종류

1. **SEO, AEO 체크리스트**
   - 타겟: N2W, SEO 블로그 관심 고객
   - 형식: PDF 다운로드

2. **숏폼 레퍼런스 모음**
   - 타겟: 숏폼 마케팅 관심 고객
   - 형식: PDF 또는 노션 페이지
   - 내용: 사무실에서 찍을 수 있는 터진 릴스 모음

3. **현재 사이트 AEO, SEO 무료 진단**
   - 타겟: 모든 잠재 고객
   - 형식: 줌 미팅 예약 또는 설문 제출

### 리드마그넷 배치

- 홈 페이지 히어로 섹션
- 각 서비스 페이지 하단
- 블로그 글 내 CTA
- 팝업 또는 슬라이드 배너 (옵션)

---

## 페이지별 우선순위

**우선순위 1**: 홈, SEO 콘텐츠 제작 (히트콘)
**우선순위 2**: N2W, 숏폼 마케팅
**우선순위 3**: 블로그, 리드마그넷 허브
